Как использовать промокоды

1

Выберите промокод

Найдите подходящий промокод из списка активных предложений

2

Скопируйте код

Нажмите на кнопку копирования или запишите код промокода

3

Примените при заказе

Введите код в поле "Промокод" при оформлении заказа

4

Получите скидку

Скидка будет автоматически применена к вашему заказу

Условия использования

Общие условия

  • Промокоды действуют только для зарегистрированных пользователей
  • Один промокод можно использовать только один раз
  • Промокоды не суммируются с другими скидками
  • Администрация оставляет за собой право изменить условия

Ограничения

  • Промокоды имеют ограниченный срок действия
  • Некоторые промокоды действуют только для определенных услуг
  • Минимальная сумма заказа может быть установлена
  • Промокоды не возвращаются при отмене заказа

Поддержка

  • При проблемах с промокодами обращайтесь в поддержку
  • Техническая поддержка работает 24/7
  • Время ответа на запросы: до 2 часов
  • Контакты: support@estetika.by
